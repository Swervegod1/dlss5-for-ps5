# Support

DLSS5 FOR PS5 is an experimental, unofficial PC-side video enhancer for PS Remote Play, compatible capture-card feeds, and local video clips.

## Before opening an issue

1. Confirm the source video works normally without the enhancer.
2. Use current desktop Chrome or Edge with graphics acceleration enabled.
3. Run **Check renderer** in the app.
4. Try 720p or 1080p and Bilinear if the preview is slow.
5. Keep a shared PS Remote Play window visible and unminimized.
6. For capture cards, verify the device works in another normal camera/capture application first.
7. Read `README.md`, `FAQ.md`, and `VALIDATION.md`.

## Where to report things

- **Bug:** use the Bug report form.
- **Feature idea:** use the Feature request form.
- **Hardware/browser result:** use the Hardware compatibility report form.
- **Security-sensitive issue:** follow `SECURITY.md` and do not publish secrets or private identifiers.

## Useful information to include

Operating system, browser version, GPU, input source, source resolution/frame rate if known, selected output height/filter/preset, renderer-check output, and exact reproduction steps.

## Scope

This project does not provide PlayStation account support, PS5 firmware support, NVIDIA DLSS support, DRM/HDCP bypass, or guarantees of improved game FPS, latency, or recovered source detail.
