PS5 Remote Play upscaling: setup and capture-card guide

Remote Play · no capture card needed

  1. Install Sony's PS Remote Play on your computer and enable Remote Play in PS5 Settings → System → Remote Play.
  2. Connect the console using Sony's app. Leave its video window open and visible. For this SDR prototype, turn off HDR in the Remote Play client.
  3. In this file, click Share Remote Play window. Pick only the Remote Play window, not this page or your whole desktop.
  4. Keep the original source window unminimized. Use Enhanced only for play; try 1080p and modest sharpening first.
  5. To use a TV, connect your computer's video output to the TV and show this preview full screen. A second display can keep Remote Play visible and focused.

Audio plays in Remote Play. This page requests video only and does not send controller input. If the controller stops responding, focus Remote Play or return to its original view.

Capture card · optional equipment

  1. Connect PS5 HDMI output → a compatible USB capture card's HDMI input → your computer. Ordinary computer HDMI ports are usually outputs.
  2. Use an unprotected SDR gameplay signal your card supports. This app cannot decode protected HDMI or streaming-service content.
  3. Click Capture card, choose the correct video device, and connect. If names are hidden, select the device and grant the browser's camera permission. Audio is not captured.

If sharing is unavailable

Download and open the actual HTML file in desktop Chrome or Edge, not an attachment preview. If your browser requires localhost, use an existing Python installation from the folder containing this file:

python -m http.server 8765 --bind 127.0.0.1

Then open http://127.0.0.1:8765/index.html. Close the terminal with Ctrl+C afterward.

What this version does — and the development path

Implemented in v0.1

A WebGL 2 filter enlarges the delivered video with bicubic interpolation, then applies bounded spatial sharpening and optional contrast. The original and enhanced sides use the same frame and output dimensions. Black bars retain the source aspect ratio.

The page keeps only current source/graphics buffers and creates no recording. Browser, GPU, video decoder, and Remote Play memory use is additional. Resolution affects GPU work and memory, not this file's disk size.

Preview updates per second count this app's drawn frames, not PS5 engine FPS or measured end-to-end latency. No quality or performance improvement is guaranteed.

Renderer check

The check draws synthetic colors and edges through the actual shader, reads GPU output, and verifies orientation, flat-color preservation, and a measurable sharpening effect. It is not a PS5 hardware or latency test.

What a future AI version needs

A small, licensed video enhancement model, stable temporal reconstruction, and benchmarks on your GPU would be a separate stage. Captured video does not include the game's motion vectors, depth, or original material data. Invented lighting or detail could flicker or change the intended artwork.

For native integration into a game we develop, Sony's approved PlayStation Partners route provides developer tools. This would not let this app patch every installed game.

PS5 Pro already offers PSSR in supported games. This project is independent and is not affiliated with Sony, NVIDIA, DLSS, or PSSR.
